# Experiment outputs

All outputs generated by this study belong here.

Planned separation:

- `dry_run/` simulated and validation outputs
- `pilot/` small paid pilot outputs
- `full_run/` frozen primary experiment outputs
- `checkpoints/` resumable request-state files
- `logs/` request metadata, token usage, provider/model identifiers, and cost records

Raw API responses must be preserved before downstream parsing or aggregation.
